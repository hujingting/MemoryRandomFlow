# 音乐封面壁纸 MVP — 产品需求文档（PRD）

**版本**：1.0  
**产品名**：音乐封面壁纸（MVP）  
**平台**：iOS、Android（手机）

---

## 1. 背景与目标

用户希望将音乐封面（单张或多张）在手机壁纸比例下预览、简单编辑，并导出为一张可设为壁纸的图片保存到相册。本 MVP 聚焦「选图 → 排版/调色 → 保存」闭环，不做账号、社区、模板商城等扩展能力。

---

## 2. 目标用户与使用场景

**目标用户**：喜欢自定义手机壁纸、且素材以专辑/单曲封面为主的用户。

**典型场景**

1. **多封面拼贴**：用户有多张封面，希望在一张壁纸里网格排列，可调间距与顺序，背景色与封面协调，最后保存到相册。  
2. **单封面大图**：用户只有一张封面，希望宽度铺满壁纸宽度、高度随图比例变化，下方留白区域颜色与图底衔接自然；可微调位置、大小与背景色，再保存。

---

## 3. 产品范围（MVP 内）

- 从系统相册选择图片（单张或多张）。  
- 按当前手机屏幕比例预览「壁纸画板」。  
- 多图：网格展示、间距调节、拖拽排序、自动背景色。  
- 单图：大图展示、位置与缩放、重点色选择、可选「自然颜色过渡」背景。  
- 将画板内容导出并保存到系统相册，并给出明确结果提示。  
- 一键清空当前编辑内容。

**明确不在本 MVP 范围内**

- 登录、云同步、社交分享链路（除系统相册保存外）。  
- 内置图库、在线搜图、AI 生成封面。  
- 视频壁纸、动态壁纸。  
- 桌面小组件、锁屏与主屏分别适配说明（若系统行为不同，以系统为准）。

---

## 4. 信息架构与页面结构

### 4.1 整体布局（自上而下）

| 区域 | 说明 |
|------|------|
| 顶部栏 | 应用标题；提供「清空」「保存到相册」操作。 |
| 画板区 | 按设备屏幕比例展示壁纸预览；无图时展示引导文案。 |
| 底部操作区 | 添加图片入口；根据当前模式展示对应调节项（见第 5 章）。 |

### 4.2 顶部栏规则

- **清空**：有内容时可点，清空图片与相关编辑状态；无内容时不可点。  
- **保存到相册**：保存过程中按钮表现为「保存中…」且不可重复触发；无图时不可保存并提示用户先添加图片。

---

## 5. 功能需求

### 5.1 添加图片

- 用户点击「添加图片」后，先选择模式：**添加一张** 或 **添加多张**。  
- **添加一张**：从相册选一张，当前编辑内容被该图**替换**为单图模式（仅保留这一张）。  
- **添加多张**：从相册一次选多张，与当前已有图片**合并**；若合并后超过 **16** 张，仅保留前 16 张，并提示用户已达上限。  
- 用户取消选择或未选中任何图时，给予轻量提示，不报错中断使用。  
- 若合并后仅剩 **1** 张图，按**单图模式**规则展示与编辑；若 **≥2** 张，按**多图模式**规则展示与编辑。

### 5.2 多图模式 — 画板与交互

- 画板内以**网格**展示所有已选图。  
- **列数规则**：当图片数量较多时（达到产品约定阈值）每行显示更多列；否则每行显示较少列（具体阈值以实现为准，需求侧约定「约 12 张及以上更密」）。  
- 每个格子为**正方形**，封面以**居中裁剪**方式填满格子，保证观感一致。  
- 用户可通过**长按拖拽**调整封面在列表中的顺序，画板即时反映新顺序。  
- 提供**间距**调节：控制格子之间以及格子与画板边缘的留白，有上下限（产品约定约 **0～20**，默认约 **8**）。  
- **背景色**：根据当前**首张**封面自动提取主色作为画板背景；无法取色时使用黑色。

### 5.3 单图模式 — 画板与交互

- 单图模式下，画板**四周不留内边距**（相对多图模式），让图片宽度与壁纸宽度对齐展示。  
- 图片以**宽度铺满**画板宽度展示，高度随图片比例变化；上下或左右留白由背景填充。  
- 用户可调整：  
  - **左右位置**、**上下位置**（有滑杆，并提供各轴**一键居中**）。  
  - **缩放大小**（有上下限，避免过小或过大不可用）。  
- 用户可在画板上通过**拖拽**移动、通过**双指捏合**缩放，与滑杆调节为同一套效果（所见即所得）。

### 5.4 单图模式 — 颜色与「自然颜色过渡」

- 从当前封面提取一组**重点色**，以横向可滑动的色点列表展示；用户点选某一色作为**手动背景色**（选中态需可辨识）。  
- 提供开关：**自然颜色过渡**（默认开启，名称以实现为准）。  
  - **开启**：根据封面**底部区域**自动识别一代表色，并将画板背景**直接设为该颜色**（纯色填充），使图片底部与下方背景在观感上更连贯。  
  - **关闭**：画板背景使用用户当前选择的**手动背景色**（来自重点色列表）。  
- 用户切换重点色、开关状态后，画板应立即更新预览。

### 5.5 清空

- 清空后：无图、多图间距与背景相关状态恢复默认、单图位置与缩放恢复默认、颜色列表与「自然颜色过渡」恢复默认策略，用户可重新开始编辑。

### 5.6 保存到相册

- 仅针对当前画板预览区域生成最终图片并写入系统相册。  
- 保存成功、失败（含权限未授权等）均需用用户可理解的一句话反馈；保存中避免用户误以为未响应而重复点击。

---

## 6. 用户可见文案（提示与按钮）

| 场景 | 期望提示或按钮状态 |
|------|-------------------|
| 画板无图 | 引导：添加图片后可预览壁纸 |
| 未选到图 | 未选择图片 |
| 选图过程异常 | 选择图片失败，请稍后重试 |
| 超过张数上限 | 最多支持 16 张图片 |
| 无图时保存 | 请先添加图片 |
| 生成图片失败 | 截图失败，请重试 |
| 写入相册成功 | 已保存到相册 |
| 写入相册失败（权限等） | 保存失败，请检查权限 |
| 保存过程异常 | 保存失败，请稍后重试 |
| 保存中 | 保存中…（按钮不可用） |

---

## 7. 验收原则（产品侧）

- 单图 / 多图两种路径均可完成「选图 → 调整 → 保存」且无死路。  
- 多图：顺序、间距、列数变化在画板上可直观看到。  
- 单图：位置、缩放、重点色、「自然颜色过渡」开关对画板背景与主体关系清晰可感知。  
- 保存结果与用户预览一致；失败场景均有明确中文说明。
